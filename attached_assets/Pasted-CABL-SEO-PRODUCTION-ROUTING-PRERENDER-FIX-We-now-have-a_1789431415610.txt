==================================================
1. PRIMARY ROOT CAUSE
==================================================

The build already generates route-specific HTML files such as:

dist/public/category/wireless-microphones/index.html

However, production clean URLs currently return:

dist/public/index.html

because the production static configuration uses a catch-all:

[[services.production.rewrites]]
from = "/*"
to = "/index.html"

Therefore:

/cabl-store/category/wireless-microphones

currently returns the homepage shell instead of the generated route HTML.

FIX THIS.

The clean production URL MUST resolve to the correct generated prerendered HTML file.
