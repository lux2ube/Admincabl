---
name: CABL Admin shared account
description: The user's chosen administrator account model for CABL.
---

CABL Admin uses one shared username and password, and authorized admins can change the credentials in Admin settings. Do not replace this with individual administrator accounts without asking.

**Why:** The user chose a single shared administrator login.

**How to apply:** Keep the Admin UI and every Admin API route behind the shared login, preserve in-app username/password changes, and do not add separate administrator accounts without asking.
