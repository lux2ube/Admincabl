---
name: Official catalog source matching
description: Rules for attaching manufacturer URLs to CABL catalog records
---

Only attach an official manufacturer URL when the page identifies the same product model or an exact match on the catalog's explicit capacity, wattage, connector, port, or form-factor details. Manufacturer homepages, collection pages, reseller pages, and pages for a different configuration are not sufficient.

**Why:** Generic accessory names often map to several current and legacy products. Assigning the wrong official page is worse than leaving a source pending because it makes the displayed specifications appear verified when they are not.

**How to apply:** Prefer exact product pages or official service product descriptions. Keep unresolved SKUs visible in the seed warning and revisit them only when a unique model match is found.

Regional listings can describe different configurations under similar product-family names. For example, the CABL UGREEN Revodok 7-in-1 match is the official 4K/30Hz page; a separate official Revodok Pro listing advertises 4K/60Hz and must not be merged into it.

**Why:** Manufacturer sites can expose multiple regional or generation-specific variants in search results, so the brand domain alone does not prove that a feature belongs to the catalog record.

**How to apply:** Match the catalog SKU, named model, port configuration, and regional product page together before copying a capability such as display refresh rate, data speed, or power delivery.
