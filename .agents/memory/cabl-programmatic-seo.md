---
name: CABL programmatic SEO
description: Durable rules for using the Yemen keyword bank without producing thin or unsupported pages.
---

Use the CABL keyword workbook as a semantic clustering source, not as a one-keyword-one-page publishing list. Keep unsupported, overlapping, location, policy, comparison, and editorial routes on `noindex, follow` until each has distinct catalog data or verified first-party content.

**Why:** The workbook contains tens of thousands of semantic template combinations but no populated search-volume or competition data. Publishing every combination would create thin pages, cannibalization, and unsupported business claims.

**How to apply:** Prioritize core category, brand-category, capacity, connector, and buying-guide routes backed by the live catalog. Use actual catalog product names in raw HTML, never mismatched fallback imagery, and generate absolute metadata plus the sitemap only after a verified production domain is available.
